# HIS 就诊记录

医院信息系统实验三项目。用原生 HTML、CSS 和 JavaScript 展示就诊记录列表与详情，所有患者资料均为虚构教学数据。

## 运行

使用 Node.js 22 或更高版本，无需安装第三方依赖。

```powershell
npm run dev
```

打开 http://127.0.0.1:4173 ，在终端按 Ctrl+C 停止服务。

```powershell
npm test
```

## 已确认的需求

- 列表显示患者姓名、科室、诊断和就诊时间。
- 点击记录进入详情；可返回列表，并支持浏览器前进、后退和详情刷新。
- 用固定的虚构数据完成演示，不连接医院系统或真实患者数据库。
- 记录需求、计划、实现、验证、提交，以及分支开发和回滚演练过程。

## 实现方案

使用浏览器原生模块、哈希路由和 Node.js 内置 HTTP 服务。页面数据保存在本地模块中，没有数据库和外部 API。服务仅监听本机地址，并只提供明确列出的静态文件。

## Git 操作说明

在 main 分支建立项目基础，在 feature/visit-records 分支开发。通过 git diff 审查改动，完成验证后提交并合并。回滚演练使用独立的 exercise/rollback 分支，先保存正常版本，再故意引入一个错误并用 git reset --hard 恢复，避免影响正常开发分支。
